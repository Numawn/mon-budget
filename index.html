Configuration Google
Google Drive (sauvegarde) + Google Vision (scan tickets) — gratuit

Guide pas-à-pas (5 minutes)

1
Allez sur console.cloud.google.com et connectez-vous avec votre compte Google.
2
Cliquez sur "Nouveau projet", donnez-lui un nom (ex: mon-budget) et cliquez Créer.
3
Dans le menu, allez dans API et services → Bibliothèque. Activez "Google Drive API" et "Cloud Vision API".
4
Allez dans API et services → Identifiants. Cliquez "Créer des identifiants → ID client OAuth 2.0". Type : Application Web.
5
Dans "Origines JavaScript autorisées", ajoutez file:// (si vous ouvrez en local) ou l'URL de votre hébergement. Cliquez Créer.
6
Copiez votre Client ID (format : xxxx.apps.googleusercontent.com) et collez-le ci-dessous.
7
Pour Vision API, créez aussi une Clé API (Identifiants → Créer → Clé API) et collez-la ci-dessous. Le quota gratuit est 1000 images/mois.
